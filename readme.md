# Placement Portal Application V2

Placement Portal Application developed as part of the Modern Application Development II (MAD-II) course.

## Roles

- Admin
- Company
- Student

## Tech Stack

### Backend
- Flask
- SQLite
- SQLAlchemy

### Frontend
- Vue.js
- Bootstrap

## Features

- User Authentication
- Role-Based Access Control
- Company Management
- Job Posting Management
- Student Applications
- Placement Tracking
